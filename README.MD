# Dharma

Prototipo inicial de la landing page de Dharma, una marca de ropa con enfoque deportivo, outdoor y de gimnasio. El proyecto podrá evolucionar a un e-commerce.

## Tecnologías

- HTML semántico
- CSS
- JavaScript vanilla
- Vite
- pnpm
- Tailwind CSS 4

## Desarrollo local

Entra a la carpeta del frontend e inicia Vite:

```bash
cd front
pnpm install
pnpm dev
